# 🚀 VendorBridge

VendorBridge is a full-stack Procurement & Vendor Management System that streamlines the complete procurement lifecycle, from vendor onboarding and RFQ creation to approvals, purchase orders, and invoice management.

## ✨ Features

* Vendor Management
* RFQ (Request for Quotation) Creation
* Quotation Submission
* Quotation Comparison
* Vendor Shortlisting
* Manager Approval Workflow
* Purchase Order Generation
* Invoice Management
* Role-Based Access Control

## 🛠 Tech Stack

**Frontend**

* HTML
* Tailwind CSS
* JavaScript

**Backend**

* PHP (PDO)

**Database**

* MySQL

**Development Environment**

* XAMPP

## 📋 Workflow

Vendor Management → RFQ Creation → Quotation Submission → Quotation Comparison → Vendor Shortlisting → Manager Approval → Purchase Order Generation → Invoice Management

## ⚙️ Setup

1. Clone the repository.
2. Place the project inside `xampp/htdocs/`.
3. Create a MySQL database named `vendorbridge`.
4. Import:

   * `database/schema.sql`
   * `database/seeds.sql`
5. Start Apache and MySQL using XAMPP.
6. Open the project in your browser.
